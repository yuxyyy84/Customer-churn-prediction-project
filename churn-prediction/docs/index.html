Which customers are about to leave?

Enter a telecom customer's details and get a churn probability with a plain risk rating. Trained on 7,043 real customers; it catches about 74% of the ones who actually leave.

Tuned for catching churn

The decision threshold is lowered from 0.50 to 0.33, so recall on churners rises from about 51% to 74%, with some loss of precision.

Honest evaluation

5-fold cross-validation, grid search and threshold tuning all use training data only. The 20% test set is touched once. ROC-AUC is 0.846.

Three models compared

Logistic Regression, Random Forest and Gradient Boosting. A tuned Gradient Boosting model won.
